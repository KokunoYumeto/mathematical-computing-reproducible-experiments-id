# O002 decision log

## O002-D001 - Original spine

No candidate is adopted wholesale. O002 is an independently authored spine
with bounded, component-licensed donor adaptations only where they add value.

## O002-D002 - Mathematical Python disposition

Mathematical Python is donor-only because its official prerequisites include
differential calculus, integral calculus, linear algebra, and differential
equations. Its completion or prior selection as a lead is not evidence for
curricular fit.

## O002-D003 - Donor role separation

Scientific Python Lectures owns the planned introductory Python/NumPy/
Matplotlib/SciPy/SymPy donor surface. RSE with Python owns the planned testing,
configuration, automation, environment, and provenance donor surface.
Mathematical Python owns only later prerequisite-aware numerical applications.
O002 authors all connective mathematical and epistemic material.

## O002-D004 - Rights separation

Original reader text is CC BY-SA 4.0 and original software is MIT. Adapted
Walls content, if admitted later, remains CC BY-NC-SA 4.0 as a separately
identified component. CC BY and MIT donor components retain attribution and
change records. Ambiguous or separately governed assets are excluded.

## O002-D005 - Build format

Quarto source with executable Python produces HTML and PDF. Stable locale-
neutral IDs and a JSON Schema-backed catalog remain additive to the Indonesian
reader. Baseline execution requires no paid or remote service.

## O002-D006 - Edition versus curriculum admission

The Indonesian edition will continue to completion even if the curriculum
selection root later chooses another B80 corpus. Sunk work and completion are
never arguments for source superiority; selection remains evidence-based and
independent.

## O002-D007 - Complete edition remains wholly original

The admitted current boundary is Units 1-12. No donor prose, exercises,
figures, data, or code entered the edition. Walls, RSE, and SPL remain bounded
comparison authorities only. Any later adaptation is a separately licensed and
reviewed revision, not unfinished work in this boundary.

includes the backend catalog, source-selection record, text/code/runtime

without verifying the corresponding current-byte evidence.
